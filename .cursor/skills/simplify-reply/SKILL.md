# Simplify Response

## Goal
Make every answer easy for a total beginner to understand — no prior knowledge assumed.

## Rules
1. **Use plain words.** Avoid jargon, acronyms, or technical terms. If one must be used, explain it right away in simple words.
2. **One idea per sentence.** Keep sentences short and clear.
3. **Use analogies.** Compare technical ideas to everyday things (e.g., "a token is like an ID card").
4. **Cut the fluff.** Only include details that help understanding — skip edge cases and technical depth unless asked.
5. **Structure visually.** Use short paragraphs, bullet points, or numbered steps instead of long blocks of text.
6. **End with a summary.** If the topic is complex, close with one simple sentence recapping the main point.

## Example
**Technical:** "The API uses OAuth2 for authentication via bearer tokens."
**Simplified:** "The app checks who you are using a secure digital key called a token — kind of like showing an ID card to get inside."
